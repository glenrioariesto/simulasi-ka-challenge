# Simulasi Deteksi Kecerdasan Artifisial (KA)

Proyek ini adalah simulasi edukasi interaktif berbasis web yang bertujuan membantu siswa untuk mengidentifikasi dan membedakan fungsi serta fitur antara teknologi otomatis/sensor konvensional dengan teknologi berbasis Kecerdasan Artifisial (KA / AI).

## Fitur Utama

- **Penyelidikan 4 Ruangan**:
  - Ruang 1: Ruang Tamu Pintar
  - Ruang 2: Dapur Pintar
  - Ruang 3: Ruang Belajar
  - Ruang 4: Ruang Server & Game
- **Interactive Eye Hotspots**: Menemukan objek-objek bermata lucu dan mengidentifikasi kecerdasannya.
- **Identifikasi Cerdas**: Membedakan teknologi sensor otomatis konvensional (Smart TV, Kipas Sensor, Kulkas Pintar, dll) dengan teknologi pembelajaran mesin AI (Voice Assistant, Computer Vision, Generative LLM, SLAM Vacuum Robot, dll).
- **Interactive Parallax Grid**: Latar belakang grid canvas responsif yang mengikuti kursor dan bereaksi ketika diklik.
- **Kemendikbud Branding**: Menggunakan logo Pusbuk Kemendikbud resmi sebagai identitas dan ikon favicon.

## Teknologi

- **Core**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Lucide Icons
- **Deployment**: GitHub Pages melalui GitHub Actions

## Cara Menjalankan Secara Lokal

1. Pasang dependensi:
   ```bash
   npm install
   ```
2. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```
3. Bangun proyek untuk produksi:
   ```bash
   npm run build
   ```
